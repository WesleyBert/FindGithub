# 🔍 GitHub Finder - Repositórios por Nome de Usuário

Este projeto é uma aplicação React que permite buscar e visualizar informações dos repositórios públicos de um usuário do GitHub. Utiliza a [API pública do GitHub](https://api.github.com) para buscar os dados.

![image](https://github.com/user-attachments/assets/b5b08487-476e-496b-a94c-964e37e5dc66)

## 🚀 Funcionalidades

- Buscar usuário do GitHub por nome de usuário (@username)
- Exibir informações básicas do perfil:
  - Foto
  - Nome
  - Bio
- Listar repositórios públicos do usuário

---

## 🛠️ Tecnologias Utilizadas

- React
- JavaScript (ES6+)
- CSS
- API do GitHub

---

## 📦 Instalação e Execução

```bash
# 1. Clone o repositório
git clone https://github.com/seu-usuario/github-finder.git

# 2. Acesse a pasta do projeto
cd github-finder

# 3. Instale as dependências
npm install

# 4. Inicie o projeto
npm start
